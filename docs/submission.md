## Подтверждено

- Финальная почтовая цепочка: инструкция по printer.md → явная просьба создать
  bug-тикет → настоящий a26b4494-1713-488c-8791-464c9fb4279e в YDB.
- Две реплики создания связаны с ticket_id; предыдущий цикл вопроса и ответа сохранён.
- API QA: четыре реплики, MCP и RAG, точное совпадение usage и YDB, тестовые записи удалены.
- Реальный дайджест доставлен оператору; статус escalated и повтор без отправки проверены.
- Injection блокируется; маскирование PII подтверждено чтением tickets/messages.
- 45 локальных тестов проходят; синтаксис скриптов деплоя и git diff --check проверены.

## Оговорки при сдаче

- Cloud Logging недоступен из-за ограниченного режима платформы. Это подтверждено
  сообщением UI; отсутствие PII в фактических облачных логах не проверено.
- Полный отказ YDB на изолированном облачном ресурсе не воспроизведён.
- Отдельные UI-фильтры модерации не подтверждены. При сбое классификатора включён
  fail-open из задания; regex остаётся активным.
- Адрес From не подтверждает корпоративную личность. Согласие ограничивается
  почтовым маршрутом; прямой MCP требует IAM, отдельного ACL сотрудников нет.
- Учебная база не является регламентом реальной компании.
- Бюджет 965–987 ₽/месяц для 300 обращений частичный: исключения есть в JSON;
  исторические строки не содержат отдельного счётчика токенов инструментов.
- Замена aiStudioAgent на foundationModelsCall согласована с преподавателем:
  runtime-agent ID несовместим с ожидаемым promptTemplateId. Скрины успешного
  workflow и письма приложены.

## Перед публикацией

Локальные материалы готовы; публикация новых файлов ещё не подтверждена.
Публикуйте вложенный Git-репозиторий, не весь каталог Project1 с черновиками.
`.env`, `.venv`, кеши и оригинал скрина с балансом исключены из Git.
Облачные ID в конфигурации не заменяют авторизацию; паролей там быть не должно.

```bash
git status --short
git diff --check
git add README.md .env.example .gitignore config docs knowledge-base prompts requirements-dev.txt requirements-rag.txt schemas scripts src tests
git diff --cached --stat
git diff --cached --check
```

Перед коммитом просмотрите состав. После коммита и отправки в GitHub проверьте:
README и картинки открываются; ссылка knowledge-base/printer.md доступна;
Hexlet CI завершился успешно; таймер поллера ACTIVE. Генерируемую
`.github/workflows/hexlet-check.yml` не изменяйте.
